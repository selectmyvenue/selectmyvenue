SELECT MY VENUE — WEBSITE V1

Files:
- index.html
- style.css
- script.js
- logo.png

Quick test:
1. Keep all four files in the same folder.
2. Double-click index.html to open the website in a browser.

WhatsApp setup:
1. Open script.js.
2. Find: const WHATSAPP_NUMBER = "";
3. Replace it with your number using India country code, e.g.:
   const WHATSAPP_NUMBER = "919876543210";
4. Save the file.
5. Refresh the website.

Important:
- The current forms use WhatsApp for a zero-cost MVP.
- No fake venue listings are included.
- For production, connect a proper form/database later.
